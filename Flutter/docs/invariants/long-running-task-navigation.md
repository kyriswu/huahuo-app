# 耗时任务与返回导航约束

## 统一约定

- 复用 `V3LongRunningTaskNotice`：提示“处理可能需要较长时间，可先返回其他界面，稍后从「消息通知」重新进入查看”，整块可点击。
- 不用一个任意秒数计时器推断任务卡死。进入真实的持续处理阶段就提示“可能较长”；结束、失败、取消或等待用户确认时按各自状态显示。
- 返回是导航，不是取消、重试、重新提交，也不是结果已读确认。优先返回实际上一层；深链没有上一层时才使用安全的页面回退地址。
- 提示只能对应一个已由应用级控制器接管或已持久化、能恢复的任务。文件选择、未确认上传、权限申请等不冒充后台任务。
- “后台”指离开当前页面，不等同于允许强制退出 App，也不承诺操作系统始终允许运行本地上传。消息通知是应用内入口，不以系统推送权限作为恢复前提。

恢复时必须区分画布会话、生成请求和服务端 Run 身份。先确认持久化成功再离页，
重新进入只观察同一任务，不创建替代任务。编辑流程结算不等于正式发布成功；
失败、待确认和取消也不能投影成处理中或成功。

历史修复与验证边界见[原审查记录](../../reports/navigation/long-running-task-navigation.md)。
