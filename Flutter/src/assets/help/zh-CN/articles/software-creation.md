# 创作空间

> 创作空间提供自由创作、个人 IP、获客营销、视觉设计、视频分析和今日推送。

创作空间用于把热点、个人资产或一个新想法整理为可继续编辑的内容。页面本身不显示思想图谱。

## 进入创作空间

在思想图谱最右侧边缘向左滑，或通过已有创作入口进入。顶部标题变为“创作空间”，底部页码同步移动。

## 今日推送

1. 在“今日推送”列表选择一条内容。
2. 进入详情后阅读标题、标签、摘要和全文。
3. 点击底部“进入创作空间”。
4. 系统会把标题和全文复制为新的自由创作草稿。

这个操作不会修改原推送。若已有未完成草稿，先按对话框选择继续旧草稿或使用当前选题新建。

## 自由创作

点击“开始自由创作”进入编辑器。可以从空白标题和正文开始，也可以从今日推送、已有草稿或创作历史继续。保存后作品进入创作历史和相应的创作内容列表，但不会因为保存就自动成为图谱资产。

## 个人 IP

1. 点击“个人 IP”。
2. 直接进入个人 IP 专项聊天。
3. 在“猜你想问”中直接选择一个定位问题，或选择唯一的资产引用项。
4. 若选择引用资产，确认一份已沉淀内容后，系统会连同问题一起发送。
5. 在后续对话中继续说明受众、平台、表达目标和输出形式。

每批推荐只有一项需要选择资产，另外两项点按后会直接发送并显示 AI 回复。
点击“换一批”后仍保持相同结构。推荐项中的资产在确认后会随该问题立即发送；
从输入栏手动添加的资产则可在发送前查看或移除。

## 获客营销

点击后直接进入获客营销专项聊天。每批推荐包含一个可选资产引用项和两个可直接
发送的获客问题。建议在后续提问中明确客户阶段、核心问题、行动目标和禁止夸大的事实。

## 视觉设计

点击后直接进入带“视觉设计”能力标签的聊天。每批推荐包含一个可选资产引用项
和两个视觉设计问题；直接问题无需先选择资产。可以继续描述使用场景、尺寸、
信息层级、文字内容和视觉偏好；AI 返回内容需要核对品牌和版权要求。

## 视频分析

点击后直接进入带“视频分析”能力标签的聊天。每批推荐包含一个可选内容资产
引用项和两个可直接发送的视频分析问题。也可以使用输入栏添加视频或发送要求，
说明分析目标，例如结构、表达、节奏或转化问题。

## 深度定位

深度定位不在创作空间工具栏中。从“我的 > 深度定位”进入，查看当前定位阶段、报告和进一步定位入口。
