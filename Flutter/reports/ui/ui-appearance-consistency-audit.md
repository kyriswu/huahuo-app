## 扫描范围与处理

扫描移动端、桌面端和共享包的主题定义、局部 Theme 边界、公共组件调用点、
条件渲染及背景采样；同时核对当前主工作区新增的长任务提示组件。下表按
组件族记录结果，不代表对每个业务页面、每种数据组合都进行了模拟器截图。

| 组件族/边界 | 发现与处理 |
| --- | --- |
| 移动端主题 | Material 的部分 surface role 和 elevation tint 原来另行推导；现在由主题 tokens 明确提供，并关闭隐式抬升染色。 |
| 顶部返回/更多等紧凑图标 | 原来已有固定 Material 实现，保留，不复制另一套控件。 |
| 思想图谱右下角 Dock | 保留唯一的 V3FeedQuickDock；底板移除实时/静态两套路径及背景采样，只在固定主题底色上绘制玻璃细节。 |
| 玻璃圆形控件、面板、Logo 底板 | 删除 shader/plain/static 竞争实现、无效的模糊与 fallback 参数和未使用的旧面板 painter；统一颜色与实际命中区域。 |
| 默认卡片 | 变体只由调用方配置决定，不再因 home/runtime scope 改变圆角和类型；底色、裁切、阴影交由唯一 surface，删除第二层填色与重复阴影。 |
| 底部面板、对话框、列表、输入框 | 保留原有公共组件和输入/焦点行为；公共主题不再叠加另一套隐式底色。没有将正常输入、错误或禁用态当成冲突删除。 |
| 主按钮和次按钮 | 交互及外观共用有效 enabled 状态；空回调不再显示可操作的边框/抬升效果，busy 主按钮不接受重复点击。 |
| 提示条 | 文字、动作和底色使用同一个解析后的 SnackBarTheme；局部深色页面通过外层 ScaffoldMessenger 发消息也不会混用明暗色。 |
| 会员页 | 修复“固定深色 ColorScheme + 外层浅色/彩色 ThemeExtension”冲突；保持既有深色金色设计，统一构造局部完整主题。 |
| 深度定位聊天、个人分身 | 保留固定紫色深色视觉身份，通过 fromTokens 一次生成 Material 角色、文字主题和 V3 tokens，删除不完整的重复覆盖。 |
| 桌面公共主题 | 同样明确 surface 与 inverse surface 角色并关闭隐式 tint，不更改桌面的主题选项。 |
| 桌面图谱缩放/模式与节点操作条 | 两处重复的背景模糊底板改用一个不透明 Material 组件；保留真实缩放、2D/3D、打开笔记与加入上下文交互。 |
| 图谱、录音及进度动画 | 保留真实数据与业务状态变化；没有替换成静态图片，也没有冻结动画来伪造“状态唯一”。 |
| 启动初始化页与诊断 probe | 属于显式的独立启动状态，不与正常页面组件合并；移除已不需要的 LiquidGlass shader 预热和 ready 触发的全树切换，保留品牌预热与业务初始化。 |

玻璃质感由固定底色上的渐变、反光与边缘绘制保留；不再采样后面的文章或
图谱像素。减少透明度时无需另换一套控件。减少动画、文字缩放、语义和真实
点击功能仍由现有无障碍/交互机制支持。

## 验证证据

- 六种移动配色 × 明/暗两种亮度，覆盖 12 个主题组合。
- 每个主题下比较 10 种上下文：基准、启动未就绪、非 home、balanced、
  constrained、滚动容器、减少动态效果、高对比度、减少透明度、不同外围背景。
  共 120 次渲染，组件图像字节和尺寸在同一主题中一致。
- 实际字体和图标使用既有 production font fixture；检查了生成的明暗组件图片。
- 16 项去重后的定向回归通过：移动组件与既有公共交互 13 项、会员主题隔离
  1 项、桌面主题 1 项、桌面真实图谱缩放 1 项。额外重跑了跨主题提示条断言。
- 变更文件静态分析无 error/warning；移动端剩余 10 条 info 级建议已与原工程
  对照，均为既有 const/花括号建议，未夹带无关格式或业务修改。
- 仅做代码扫描、widget 渲染与定向交互验证；未执行全套测试、逐页模拟器遍历、
  真机或生产后端验证。未修改后端、服务端或任何请求协议。
