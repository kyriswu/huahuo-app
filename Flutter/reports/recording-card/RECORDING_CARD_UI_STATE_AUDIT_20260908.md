# 录音卡 UI 与同步状态审查

审查日期：2026-09-08（本地时区 Asia/Shanghai）。

## 范围与原则

阅读录音卡控制、设备管理、设备详情、卡内文件、个人录音库，以及 BLE/Wi-Fi 操作仲裁、同步台账、自动同步、录音库核验、转写回执和相关 Provider。

只修改 Flutter；不修改后端、原生 SDK、线上数据或无关功能。后端录音列表及转写完成事实的实现已作只读核对，没有把列表中的排队/处理中字符串当作最终转写证据。

显示状态应是当前事实的投影，不是另一个需要自行恢复的状态机。统一投影入口：

`src/lib/features/recording_card/application/recording_card_file_presentation.dart`

继续使用现有硬件操作租约与状态机，不新增另一套传输控制器。历史数据仍可读取，但不能用旧推断分支把不确定状态包装成成功、删除或进行中。

## 标签的三个独立维度

1. 卡内存在性：源文件存在，或有明确卡内删除凭据。
2. 本地可用性：未同步、排队、传输/校验/入库、已同步、显式删除、缺失或待核验。
3. 转写事实：有最终转写回执，或当前任务正在处理/失败；未确认不能冒充已完成。

因此，“已转写 + 本地已删除”可以合法同时出现：本地音频删除不等于历史转写结果被撤销。“已同步”表示录音卡音频已落入本地，不代表云端上传或转写完成。

## 本地同步显示规则

| 证据或阶段 | 显示 | 不允许的推断 |
| --- | --- | --- |
| 未同步源文件 | 未同步 | 不能因有历史任务就认为已同步 |
| 台账 queued，尚未取得传输执行权 | 等待同步 | 不显示同步中 |
| 当前卡、当前源文件、有效 BLE/Wi-Fi 操作 | 同步中 | 不使用旧连接或其他卡的进度 |
| 校验/本地入库 | 正在校验 / 正在入库 | 字节到达 100% 不等于入库完成 |
| 已暂停批次 | 同步已暂停 | 不显示仍在传输 |
| 持久化 syncing，但没有活动操作 | 同步待恢复 | 不把上次中断当作当前进行中 |
| 台账或原生核验事实与本地可用音频一致 | 已同步 | 不依赖搜索结果页是否恰好包含该录音 |
| 本地目录尚未完成核验 | 本地待核验 | 不提前断言文件已删除或已丢失 |
| 有明确本地删除台账 | 本地已删除 | 不自动重新下载用户已删除的本地文件 |
| 已核验本地目录，但原同步音频不存在 | 本地文件缺失 | 不冒充用户主动删除 |
| 本地删除正在执行 | 正在删除本地 | 不提前写成删除完成 |
| 历史状态无法确认 | 同步状态待确认 | 不以旧状态字符串补出成功结果 |
| 同步失败 | 同步失败 | 不显示历史终态的 100% 进度 |

卡内明确删除的源文件从列表与详情统计中排除。删除凭据只能作用于对应源身份，不得通过相同音频哈希隐藏另一个新源文件。两条不同卡内源录音即使去重后共用同一本地对象，仍按两条卡内文件统计。

## 转写状态与刷新

- “已转写”只来自与本地 ID、源身份、内容哈希兼容的持久化完成回执。
- 当前任务的 uploading/processing/failed 可以显示处理中或失败；仅有 ready 状态、没有最终回执时，不补出已转写。
- 普通列表不额外堆叠未确认的转写标签；详情/播放器可以明确说明尚未转写或暂无法确认。
- 回执存储在成功持久化后通知页面，完成标签无需离开页面再进入才更新。
- 非 UI 依赖读取回执 Store 的 notifier 身份，避免回执通知重建正在运行的转写协调器、批处理控制器。

## UI 与交互修复

- 个人录音库不展示后台录音卡同步/Wi-Fi 面板，也不订阅无关卡上传进度。
- 卡内任务按卡身份隔离；旧卡遗留的 Wi-Fi 批次、进度与完成反馈不能出现在另一张卡的页面。
- 自动同步、手动操作和 Wi-Fi 流程避免重复展示进度面板；后台路由不重复弹出完成提示。
- Wi-Fi 使用冻结的台账源身份匹配断开 BLE 后的缓存行，避免标签与活动文件脱节。
- 快捷 Wi-Fi 的按钮可用性与实际排队文件使用同一个卡内文件投影，不误用仅包含本地录音的管理列表。
- Wi-Fi 弹窗在首帧挂载后才启动硬件准备命令，避免构建期间修改共享 Provider。
- 空闲、等待、暂停、失败面板不持续播放不确定进度动画；没有真实进度时也不重播历史百分比。
- 批量选择时显示可选择的录音行，不被已展开的播放器替换。
- 录音行元信息自适应换行与高度，覆盖窄屏和放大字体。
- 完整控制页的设备头部只显示连接状态，控制区域只显示录音/传输活动，消除重复的“已暂停”“录音中”。只有一个状态区域的紧凑控制组件保留组合状态。

## 已移除的遗留路径

- 卡内文件页和详情页各自实现的台账覆盖、文件匹配、删除推断及统计分支。
- 录音库组件内一次性拉取前 100 条远端录音并缓存转写状态的逻辑。
- 旧后端转写状态字符串解析与不响应回执变化的标签缓存。
- 基于历史任务总数、过期原生字节计数计算当前整体百分比的逻辑。
- 个人录音页依赖全局自动转写状态展示录音卡面板的条件。

没有删除仍被真实流程使用的操作仲裁、恢复台账、最终回执或兼容数据读入逻辑。
