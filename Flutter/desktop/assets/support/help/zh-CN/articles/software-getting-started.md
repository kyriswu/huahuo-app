# 快速开始

> 当前首页由“思想图谱”“创作空间”和可关闭的“代表作”组成；左上角入口打开“我的”。

花火 AI 用于采集真实内容、整理个人资产，并在这些资产的基础上进行 AI 对话和创作。推荐先完成少量内容采集，再逐步沉淀，不需要在第一次使用时配置所有功能。

## 登录与首次使用

1. 打开应用，输入有效手机号。
2. 点击“获取验证码”，收到短信后输入六位验证码。
3. 阅读并勾选《用户协议》和《隐私政策》，再点击“登录 / 注册”。
4. 登录后应用会恢复当前账号的工作区。
5. 首次登录按页面提示完成内容方向或定位信息；保存成功后进入首页。
6. 如果会话恢复失败，可先重试；需要更换账号时选择“使用手机号登录”。

## 认识首页

- **思想图谱**：查看已经沉淀的个人资产及其关系。
- **创作空间**：使用今日推送、自由创作和四种专项创作能力。
- **代表作**：达到展示条件后查看和编辑代表作，可在设置中关闭。
- **我的**：查看账号、等级、资产、录音卡、外部世界和设置。

从思想图谱右侧边缘向左滑进入创作空间；从左侧边缘向右滑打开“我的”。创作空间和代表作之间可以左右滑动，底部页码用于确认当前位置。

## 第一步：采集内容

思想图谱底部提供“+”“独白”和“文字”：

- 点击“文字”新建笔记。
- 点击“独白”开始个人录音。
- 点击“+”后可选择外录、内录、链接或导入。

采集过程中按页面提示授予麦克风、文件、相册或本地网络权限。任务未完成前不要删除正在处理的本地文件。

## 第二步：确认沉淀

采集或订阅得到的内容不会仅因为被查看就自动进入思想图谱。打开内容详情，选择“沉淀到我的资产”，确认分类或文件夹后完成沉淀。允许暂不分类，之后再整理。

## 第三步：使用思想图谱

沉淀完成后回到思想图谱。你可以在 2D 与 3D 之间切换，搜索内容，筛选节点，拖动或缩放视野，并点击节点查看详情。资产达到聚合条件后，可以启动聚合并在消息中心查看进度。

## 第四步：开始创作

进入创作空间后，可以：

- 打开今日推送并复制为新的自由创作草稿。
- 从空白文档开始自由创作。
- 选择个人 IP 或获客营销，并先指定要引用的资产。
- 直接进入视觉设计或视频分析对话。

保存后的作品进入创作历史。AI 输出应在核对事实、数字和引用后再使用。

## 建议习惯

- 原始事实、个人判断和 AI 建议分开记录。
- 只沉淀未来会复用的内容，并及时补充分类和文件夹。
- 录音结束后先确认本地文件存在，再进行上传或转写。
- 删除和永久删除含义不同；永久删除前先确认无需恢复。
