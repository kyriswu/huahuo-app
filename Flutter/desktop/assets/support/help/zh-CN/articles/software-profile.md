# 个人中心

> 从思想图谱左上角点击菜单，或从左侧边缘向右滑，打开“我的”侧边面板。

“我的”集中展示账号资料、等级、资产新增、录音卡状态和个人功能入口。

## 个人资料

点击顶部头像与昵称区域进入个人资料。手机号以脱敏形式显示；修改头像、昵称或其他资料后，以页面明确显示的保存结果为准。

## 等级与成长

等级卡用于展示当前阶段和进度，本身不可点击。首次定位报告和进一步定位报告对应前两个成长阶段；后续等级根据有效沉淀数量逐步提升。

如果沉淀数量增加但等级没有变化，先确认内容仍是有效沉淀，并检查定位阶段是否完成。

## 资产新增与日历

点击“资产新增”卡片进入活动日历：

1. 在紧凑月视图选择日期。
2. 使用“今天”快速回到当前日期。
3. 按内容类型筛选活动。
4. 在当日时间流查看使用记录和内容变化。

周/月切换只改变统计观察范围，不会删除资产。

## 录音卡状态

录音卡组件显示连接状态、录音状态、计时和电量。点击组件非控制区域进入设备与文件管理；开始、暂停、继续和停止按钮只发送对应设备命令。

设备未上报电量时显示双横线，不代表电量为零。

## 个人功能入口

当前入口依次包括：

- **深度定位**：查看当前报告和进一步定位入口。
- **外部世界**：管理频道订阅和知识广场。
- **我的资产**：管理沉淀、分类、文件夹和影像。
- **会员与额度**：查看当前权益、额度和可选方案。
- **花火商学院**：功能未开放时页面会明确提示。
- **帮助与反馈**：阅读离线帮助或填写反馈。
- **设置**：管理外观、账号、声纹、权限、代表作和版本。

## 会员与额度

1. 进入“会员与额度”。
2. 查看当前会员状态与额度。
3. 横向选择 PRO 或 MAX 权益方案。
4. 选择计费方式并阅读服务协议和自动续费协议。
5. 未勾选协议时支付按钮不可用。

只有页面明确显示支付成功和会员状态更新，才表示操作完成。

## 退出登录

点击面板底部“退出登录”，在确认框中再次确认。退出后需要重新获取验证码登录；不同账号的草稿、历史和本地元数据按账号隔离。
