# 创作空间

> 创作空间提供自由创作、个人 IP、获客营销、视觉设计、视频分析和今日推送。

创作空间用于把热点、个人资产或一个新想法整理为可继续编辑的内容。页面本身不显示思想图谱。

## 进入创作空间

在思想图谱最右侧边缘向左滑，或通过已有创作入口进入。顶部标题变为“创作空间”，底部页码同步移动。

## 今日推送

1. 在“今日推送”列表选择一条内容。
2. 进入详情后阅读标题、标签、摘要和全文。
3. 点击底部“进入创作空间”。
4. 系统会把标题和全文复制为新的自由创作草稿。

这个操作不会修改原推送。若已有未完成草稿，先按对话框选择继续旧草稿或使用当前选题新建。

## 自由创作

点击“开始自由创作”进入编辑器。可以从空白标题和正文开始，也可以从今日推送、已有草稿或创作历史继续。保存后作品进入创作历史和相应的创作内容列表，但不会因为保存就自动成为图谱资产。

## 个人 IP

1. 点击“个人 IP”。
2. 在“选择你的资产”中搜索并多选已沉淀内容。
3. 确认选择后进入带资产上下文的聊天。
4. 在对话中说明受众、平台、表达目标和输出形式。

已选择资产会持续作为当前专项对话的上下文，聊天顶部可查看数量和标题。

## 获客营销

操作与个人 IP 类似：先选择要引用的资产，再进入专项聊天。建议在提问中明确客户阶段、核心问题、行动目标和禁止夸大的事实。

## 视觉设计

点击后直接进入带“视觉设计”能力标签的聊天，不要求预先选择资产。可以描述使用场景、尺寸、信息层级、文字内容和视觉偏好；AI 返回内容需要继续核对品牌和版权要求。

## 视频分析

点击后直接进入带“视频分析”能力标签的聊天。使用输入栏添加资料或发送视频相关要求，说明分析目标，例如结构、表达、节奏或转化问题。

## 深度定位

深度定位不在创作空间工具栏中。从“我的 > 深度定位”进入，查看当前定位阶段、报告和进一步定位入口。
