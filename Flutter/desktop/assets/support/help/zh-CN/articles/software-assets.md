# 我的资产与沉淀

> “我的资产”当前按已沉淀、经历、知识、观点、创作、资讯和影像组织内容。

“我的资产”用于管理已经沉淀的内容、固定分类、文件夹和独立照片相册。外部文章只有执行沉淀后，才会复制为个人资产并进入思想图谱。

## 打开我的资产

1. 从首页左上角或左侧边缘打开“我的”。
2. 点击“我的资产”。
3. 左右切换已沉淀和各资产分类。

“已沉淀”显示当前账号全部有效沉淀记录；经历、知识、观点、创作和资讯显示对应固定分类。

## 沉淀内容

1. 打开一篇可沉淀的内容。
2. 点击“沉淀到我的资产”。
3. 选择一个或多个固定分类，也可以暂不分类。
4. 如需整理位置，选择现有文件夹或新建文件夹。
5. 确认后等待页面显示“已沉淀”。

沉淀会保存个人副本，不修改外部世界中的频道原文。未分类内容仍保留在“已沉淀”中，并可稍后整理。

## 文件夹管理

- 点击新建入口创建文件夹。
- 进入文件夹后可继续创建子文件夹。
- 使用文件夹右侧菜单进行重命名或删除。
- 删除文件夹前阅读确认提示；文件夹和内容本身是不同对象。

## 查看和整理笔记

笔记列表支持展开正文、查看不同内容阶段和使用笔记操作菜单。根据当前状态，可进行分享、导出、管理标签、重命名、同步或删除。导出时可以选择 Markdown 或 PDF。

## 影像相册

“影像”是独立照片相册：

1. 进入“影像”。
2. 点击右上角添加照片。
3. 从系统相册一次选择最多 9 张受支持图片。
4. 点击照片进入全屏预览并缩放查看。

照片保存在当前账号的私有目录并进行重复检查。影像不会自动变成笔记，也不参与思想图谱和资产等级计算。

## 移出、删除与回收站

- 移出某个固定分类不一定会删除沉淀记录，内容仍可能保留在“已沉淀”。
- 普通删除会把支持恢复的笔记、创作或沉淀资产移入回收站并保留 30 天。
- 在“我的 > 设置 > 回收站”中可以恢复或永久删除。
- 永久删除和清空回收站不可撤销，操作前必须再次确认。

分享和导出只使用安全文件引用，不会在页面中显示应用私有路径。
