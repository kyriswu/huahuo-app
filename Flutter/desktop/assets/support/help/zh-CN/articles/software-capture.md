# 内容采集与导入

> 内容采集入口集中在思想图谱底部：文字、独白，以及“+”菜单中的外录、内录、链接和导入。

内容采集把现场记录、网页或本地文件转换为可检索内容。采集完成不等于已经进入思想图谱，仍需在内容详情中确认沉淀。

## 新建文字笔记

1. 在思想图谱底部点击“文字”。
2. 输入标题和正文。
3. 使用编辑器完成必要的段落和文字格式。
4. 点击右上角保存。
5. 返回前若仍有未保存内容，按提示选择继续编辑或放弃。

## 独白录音

1. 点击底部“独白”。
2. 首次使用时允许麦克风权限。
3. 点击开始录音，页面显示计时、波形和实时文字预览。
4. 需要中断时选择暂停，再点击继续。
5. 点击停止，等待本地录音保存和后续处理。

实时文字仅用于录音过程预览，正式内容以完整录音上传后的转写结果为准。网络异常不会自动删除已经保存的本地录音。

## 外录与内录

点击“+”后选择：

- **外录**：用于现场会议或多人对话，按页面提示开始、暂停和结束。
- **内录**：用于采集设备内部播放的声音，开始前按系统提示配置屏幕采集或音频权限。

录音时不要同时启动另一个会占用麦克风或系统音频的应用。

## 导入链接

1. 点击“+ > 链接”。
2. 输入完整的 `http` 或 `https` 地址。
3. 点击提交并观察处理状态。
4. 处理完成后打开生成的内容详情。
5. 失败时检查链接是否公开可访问，再按页面提示重试。

需要登录、付费、地区权限或已经删除的网页可能无法导入。

## 导入本地文件

1. 点击“+ > 导入”。
2. 选择本地文档导入。
3. 点击选择文件，可一次选择多个文件。
4. 当前支持音频、TXT、Markdown、PDF、DOC、DOCX、PPT 和 PPTX。
5. 确认已选择列表，等待每个文件完成处理。

从其他应用“用花火 AI 打开”文件时，应用会先显示外部文件确认页；确认后才创建导入任务。取消文件选择不会生成内容。

## 完成、失败与内容去向

- 任务进行中保持文件可访问，不要移动或删除原文件。
- 成功后打开内容详情，检查标题、原始内容和转写结果。
- 失败任务会显示明确状态；保留原文件后重试即可。
- 需要进入思想图谱时，在内容详情中执行“沉淀到我的资产”。
