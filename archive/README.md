# 历史资料归档

此目录保存过去交接和调试的原始资料，不是当前产品源码或开发规范。
其中的命令、部署步骤、SCM 镜像规则和绝对路径仅反映当时环境。
当前工作流以根目录 `AGENTS.md` 和 `Flutter/docs/DEVELOPMENT_WORKFLOW.md` 为准。

- `docs/`：历史架构/迁移/支付方案、审查报告、文案及交接基线。
- `snapshots/`：后端提交 `709ad05` 的导出包、0008 前端抽取包、ADT 页面及历史隐私协议。
- `evidence/`：录音卡原始诊断、测试源码、夹具和历史回执。
- `recordings/`：两份历史测试录音，保留原文件名及内容。

后端快照内的 `PACKAGE-MANIFEST.txt` 保留原提交号和导出说明。归档包内部路径及
内容保持原样；外部项目路径不会因本次移动而变成当前可运行的工具入口。
重复 ZIP 和旧 Windows 测试 EXE 已移除，对应解压内容及测试源码仍保留。
新增 Flutter 验证证据继续放入 `Flutter/reports/`。

原根目录及 `测试脚本/` 中的脚本现位于 `tools/smoke/`。历史文档中的外部绝对路径、
旧命令和当时状态保留原文，不代表当前部署或测试结论。
