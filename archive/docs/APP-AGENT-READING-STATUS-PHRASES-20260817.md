# App Agent 工具后缀词库

## 1. App 拼接规则

本文件中的条目全部是**工具后缀词**，不是完整句子。App 收到真实工具调用
事件后，用工具动作、后缀词和“中”拼成最终展示文案。

| 工具名 | 拼接模板 | 后缀示例 | 最终展示 |
| --- | --- | --- | --- |
| `read` | `阅读 + 后缀 + 中` | `用户定位文档` | `阅读用户定位文档中` |
| `write` | `写入 + 后缀 + 中` | `内容草稿` | `写入内容草稿中` |
| `workspace_search` | `查找 + 后缀 + 中` | `用户相关素材` | `查找用户相关素材中` |
| `huahuo_video_analyze` | `分析 + 后缀 + 中` | `视频画面` | `分析视频画面中` |
| `image_generation` | `生成 + 后缀 + 中` | `封面主视觉` | `生成封面主视觉中` |

使用规则：

1. 先按 `agentProfileId` 进入对应 Agent，再按真实 `toolName` 进入工具分组。
2. 只从该工具分组随机选择后缀，不跨工具混用。
3. 后缀本身不再添加“读取、写入、搜索、分析、生成、正在、中”等动作词。
4. 每次真实工具调用抽取一次；没有工具调用时不展示工具文案。
5. 同一 Run 最近 12 个后缀不重复。
6. 如果接口已经提供可公开的真实业务文件名，优先显示真实名称，不再随机。
7. 以下每个 Agent 合计 100 个后缀；通用池也合计 100 个。

```json
{
  "renshe_neirong_agent": {
    "read": ["用户定位文档", "Note 原文", "用户经历资产"],
    "write": ["Note 草稿", "人设内容初稿", "用户知识资产"]
  },
  "video_analysis_agent": {
    "read": ["视频分析方法", "专业报告规范"],
    "workspace_search": ["当前视频资料", "视频关联 Note"],
    "huahuo_video_analyze": ["视频画面", "视频字幕", "视频时间线"],
    "write": ["视频诊断报告", "视频优化建议"]
  }
}
```

推荐拼接函数：

```text
toolVerb = {
  read: "阅读",
  write: "写入",
  workspace_search: "查找",
  huahuo_video_analyze: "分析",
  image_generation: "生成"
}

suffix = random(agentPools[agentProfileId][toolName])
displayText = toolVerb[toolName] + suffix + "中"
```

## 10. 不应作为后缀展示的内容

- 服务器绝对路径、Workspace 绝对路径和临时物化路径
- `AGENTS.md`、`SOUL.md`、`TOOLS.md`、`SKILL.md` 等内部配置文件名
- Skill 内部引用文件的真实路径及扩展名
- Workspace ID、Thread ID、Run ID、Note ID 和 Material ID
- 哈希、版本、Provider、Token、工具参数和错误栈
- 其他用户或其他 Workspace 的任何信息
